# 📚 StudySync – Online Learning Platform (Frontend)

**StudySync** is a responsive landing page for an online education platform. Built with pure **HTML** and **CSS**, this project focuses on clean UI/UX, responsive design, and modern aesthetics — ideal for learning front-end fundamentals.


## ✨ Features

-  **Fully Responsive** – Works smoothly on desktops, tablets, and mobiles.
-  **Modern Layout** – Clean, minimal design with intuitive sections.
-  **Semantic HTML** – Accessible and SEO-friendly structure.
-  **Custom CSS Styling** – From layout to buttons and animations.

## 🚀 Technologies Used

- HTML5
- CSS (Flexbox, Grid, Media Queries)

## 💡 Sections Included

- Navigation Bar
- Hero Section
- About / Features
- Testimonials / Reviews
- Newsletter Signup
- Footer
